# Basit_API_Projem

Projenin temel amacı; modern bir API mimarisinin nasıl çalıştığını göstermek, verileri güvenli ve düzenli bir şekilde yönetmek (CRUD süreçleri: Oluşturma, Okuma, Güncelleme, Silme) ve istemci uygulamalarına (Web, Mobil veya diğer servisler) arka plan hizmeti sunmaktır.

## Proje Ne İşe Yarar?
* Veri Yönetimi: HTTP uç noktaları (endpoints) aracılığıyla verilerin sunucu tarafında işlenmesini ve saklanmasını sağlar.
* Servis Altyapısı: Farklı istemcilerin (frontend, mobil veya üçüncü parti uygulamalar) aynı veri kaynağına güvenli bir şekilde erişmesine olanak tanır.
* Test Edilebilirlik: Entegre Postman arayüzü sayesinde tüm uç noktaların interaktif olarak test edilmesini sağlar.

## Teknolojiler
* C# / .NET Core
* ASP.NET Core Web API
* Postman
